# Xedra：情绪渐进回蓝

这是 CPH 内置的可选平衡 MOD，依赖 Xedra 超进化（`xedra_evolved`）和
启用了 Lua Platform 的游戏构建。MOD ID：`xedra_smooth_mana`。

## 玩法

梦行者在平静时也会缓慢恢复魔力，恢复速度随总士气的绝对值连续增长：

```text
自然恢复倍率 = 0.10 + abs(总士气) / 41
```

正负情绪同等有效，35点处没有开关或跳变。下表相对于普通基础恢复速度，
不含装备、变异等其他恢复修正：

| 总士气 | 恢复速度 |
| --- | --- |
| 0 | 10% |
| ±10 | 34.39% |
| ±20 | 58.78% |
| ±34 | 92.93% |
| ±35 | 95.37% |
| ±36 | 97.80% |
| ±50 | 131.95% |
| ±100 | 253.90% |

平静时的10%是保守设置；在魔力上限和其他条件不变时，理论上从空回满
约需80个游戏小时。角色面板中的“平静或无聊”和“充满热情”改为统一的
“情绪回流”。心胜于物的灵能消耗不受影响。

## 启用和移除

创建世界时，在模组列表中选择“Xedra：情绪渐进回蓝”。依赖会让它在
Xedra 超进化之后加载；内置提供不代表默认启用。

已有世界须先退出游戏并备份世界的 `mods.json`，再向数组末尾加入
`"xedra_smooth_mana"`。移除时从世界的模组列表移除此 ID。
该 MOD 不生成地图内容。

如果以前安装过同 ID 的个人版，先备份它，再将整个个人版文件夹从用户
目录的 `mods/` 移到该目录之外，使用游戏内置版本。世界中的 MOD ID
保持不变，也不要同时安装多个同 ID 副本。

## 低速恢复和兼容范围

游戏每三分钟结算一次自然回蓝，并舍去小数。仅改为10%时，魔力上限低于
1600的角色可能仍然一直回复零。因此附带的 Lua 为玩家梦行者保留每次
结算丢失的小数，凑满1点才补回；引擎已恢复的整数不会再次增加。
魔力1000、士气0的例子：每三分钟应恢复0.625点，24分钟合计恢复5点。

补偿读取引擎最终恢复率，包含装备和其他恢复修正。满蓝、恢复率为零或
失去梦行者时清除余数，不会在满蓝时储存额外魔力。接管 NPC 时也清除
原身体的余数。余数使用随角色保存的 Lua 状态。回合后段采样前若更换装备
或改变属性，该次采样可能与回合前段
的原生恢复率略有不同。

NPC使用同一条连续倍率，但没有玩家的小数补偿。单人玩法是验证目标；
多人联机需另行确认。其他同时重定义 `dreamer_regen_no` 或
`dreamer_regen_yes` 的 MOD 会有加载顺序冲突。

## 开发验证

原生回归位于 `tests/lua_platform_xedra_smooth_mana_test.cpp`，需显式加载
`xedra_evolved,xedra_smooth_mana` 后运行 `[xedra_smooth_mana]`。
测试使用独立用户目录，不应对真实存档执行。
