# CPH 中文补译风格

本轮用户要求：黑色幽默、冷笑话。只补齐缺口，现有人工作品和有效上游译文优先保留。

- 叙述、物品描述、对白采用克制的黑色幽默和一本正经的冷面表达。把荒诞说得像日常，把灾难说得像糟糕的售后；笑点来自原有情境和措辞，不另编事实。
- 保留人物身份、说话习惯、敌意、恐惧及原文粗口强度。角色认真或悲伤时不强加俏皮话。讽刺与双关可自然转译，但不能更改任务含义、剧情线索或世界设定。
- 不额外添加笑话尾巴、网络热梗、括号吐槽、现代品牌或译者评论。原文没有的信息不能凭风格补出来。
- 界面按钮、属性、伤害、配方、设置、错误信息、操作说明和物品名称首先保证准确简洁，不为搞笑牺牲可玩性。
- 使用既有中文术语；同名实体保持一致。占位符、数字、单位、标签、动态替换及换行必须保真，必要的 printf 参数编号重排交由 GNU gettext 检查。

生成结果仍需审阅。自动格式检查不等于人类已确认语言质量。
