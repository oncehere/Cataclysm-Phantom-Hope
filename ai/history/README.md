# Inherited CCB governance evidence

Files in this directory preserve the CCB repository audit and complete PR artifact publisher test from the source history. They describe `CrimsonCrossBunker/Cataclysm-Cleanwater-Bomb` and `.github/workflows/publish-pr-artifacts.yml`, which was removed before this cleanup. The test was retired from active discovery because its workflow no longer exists; this does not lower a current CPH gate. Current remote workflow inventory checks live in `tests/project/test_remote_workflows.py`. CPH's current observation and deferred gates are in `ai/repository-settings.target.yml`; active agent checks are listed in `ai/test-matrix.yml`.

The completed CCB document migration is retained at [the fixed source revision](https://github.com/oncehere/Cataclysm-Phantom-Hope/tree/1057a15bf802572b7497ffd9617083a9b6935321/doc/migration), together with its importer, generators, finalizer, and tests in that revision's `tools/agent/`. Those retired tools and expanded reports are no longer part of the current tree or routine validation.

[ccb-document-origins.yml](ccb-document-origins.yml) retains only the stable document IDs, historical destination IDs, contributors, and licenses needed for the 174 inherited document paths still present at retirement. Its `source_commit` identifies the original CCB input; `source_inventory` pins the complete migration record, including retired paths and rejected-attribution summaries. These are historical provenance, not a new migration backlog or a substitute for each current file's license. Current documentation classification reads this compact input without fetching or replaying the old migration history.
