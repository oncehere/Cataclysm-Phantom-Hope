# Multiplayer source attribution and scope

This is the source manifest for the CPH multiplayer adaptation of
[busterbogheart/Cataclysm-DDA-multi](https://github.com/busterbogheart/Cataclysm-DDA-multi).
The source interval excludes `79113712e4469b931b568b388f6e1f89326e3a01` and
includes `5cf9a79c66ec82ea6d5710fb277db5ac62a71681`. The CPH adaptation starts
from `df8fe8ead66bbdfe9efb307ea4367bc121138db1`.

The interval contains 486 first-parent commits, plus four commits merged by
PR #22 (490 commits in the full graph). The table below retains all 233
first-parent commits that contribute to the selected final multiplayer effects,
including intermediate states and reversals, and all four translation-side
commits. A listed source is attribution and provenance; it does not assert that
every hunk in that commit was imported or that multiplayer runtime validation
passed. CPH takes the final multiplayer effects and their required hooks while
preserving its existing single-player, Lua, translation, and product behavior.

The detailed task record separates source classification, user decisions,
implementation coverage, and validation. It is independent of the fixed CDDA
pre704 ledger. The dated record retains the full 486-source classification,
paths, complete commit messages and source chains; this portable document
retains the selected source IDs and paths alongside the shipped source.

## Scope and final-state choices

| First-parent classification | Count | CPH treatment |
| --- | ---: | --- |
| Selected multiplayer source | 233 | Adapt the final effect and required peripheral hooks; retain reversals. |
| Pure CDDA content/framework history | 212 | Excluded from this multiplayer update. |
| Upstream documentation chronology | 19 | Use current verified networking/compatibility facts in CPH documentation; do not replay product history. |
| Brand, Donate, art, default Coop menu | 15 | Excluded; preserve CPH identity and existing single-player route. |
| Upstream release/site controls | 5 | Excluded; retain CPH build/release controls. |
| Unrequired generic changes | 2 | Excluded: unrelated mapgen symptom suppression and ignore-file changes. |

The selected effects include sleep/long-activity synchronization, cooperation
UI and controls, address privacy/ports, reconnect/performance fixes, and
experimental Magiclysm support. Experimental means that unresolved upstream
limitations remain visible; it does not claim complete synchronization for all
spell effects, arbitrary mod combinations, or distant world generation.
Aftershock: Exoplanet retains its explicit incompatibility explanation.

The final source state removes the incomplete item fingerprint experiment,
uses ground-item clear/rebuild with reference guards, removes the old first-aid
patient hold in favor of range cancellation, permits the locked debug menu,
restores the mount restriction/sync guard after its reversal, uses the thin
intent caret, and shows actor percentage progress only for spellcasting.
These reversals are kept in the source table rather than counted as separate
features to apply.

## Reproduction and history preservation

The original upstream commits remain identifiable by their complete IDs, not
by title or patch similarity. Fetch the fixed source commit into a separate
source checkout, then inspect the interval with `git log --first-parent` and
`git show --no-renames`; include the four side-branch IDs when checking the full
graph. Compare the fixed source baseline to the source end state, then review
only the selected multiplayer hunks against the CPH baseline. Shared CPH files
are adapted at the hook/API level, not replaced with whole upstream files.

Keep durable fixed source refs, complete commit metadata and the selected source
exports alongside the dated task evidence. Verify their archive manifest before
retiring temporary exports. A partial promisor graph still needs its declared
object store or upstream for unexported blobs; it is not a complete offline
history bundle. A repository merge of
the whole upstream branch is not required to preserve authorship or history and
would pull unrelated CDDA/product changes into this scoped update. The dated
authoritative records and exact source refs/archive are retained independently of
local temporary export/build directories. CPH adaptation commits, local tests,
hosted CI, merges, installation, and real multiplayer runs are separate facts.
