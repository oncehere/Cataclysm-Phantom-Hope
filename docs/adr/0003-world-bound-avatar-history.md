# 化身经历和成长跟随所加载的世界存档

2026-10-19，用户确认 Q15 采用推荐方向：世界内记忆、承诺、任务进度和经历产生的成长恢复到所加载存档对应的状态；角色初始设定和玩家明确设置的偏好继续保留。这个选择放弃默认的跨时间线记忆，以保持角色所知与当前世界经历一致；跨时间线记忆若要成为玩法，必须另行明确开启。

读档使旧模型请求失效，已保存任务核对当前世界条件后才继续。存档恢复不得凭空重放已经完成的物理效果，也不得把回滚时间线的未来记忆或提示留在普通界面。当前本地实现将版本化任务状态及玩家已知动作随世界保存；独立调用消费账本不随读档回滚，未知任务格式保留原文并暂停接管。具体检查点协调及调用额度等运行管理状态见[完整设计草案](../project/companion-avatar-design.md)，已验证范围见[验收契约](../../companion/docs/acceptance.md)。
