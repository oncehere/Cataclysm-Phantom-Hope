# 化身保留连续意图，本地行动遵守职责与承诺

2026-10-19，用户将同伴定位为“LLM 在虚拟世界中的化身”，并确认 Q8—Q11 全部采用推荐方向。同伴可在事先约定的长期职责和资源、风险范围内主动安排工作，无需逐项批准；熟悉的日常流程由本地执行，需要新取舍时交给 LLM。离队探索、建立新据点、动用稀缺公共物资等超出原约定的事项需要另行约定。

本地层延续角色已作出的决定，可根据稳定偏好调整路线、节奏及允许的替代手段；改变承诺、关系立场或重大资源分配属于明确的新决策。普通不便不能由执行优化悄悄转成弃单，紧急危险先暂停任务。角色设定允许违约时，违约仍须作为明确角色决定处理并留下相应记忆。这个边界以增加职责和意图状态的维护，换取模型缺席时仍可行动、同时不让本地自动行为擅自改变角色立场。

游戏内请求允许角色拒绝或协商，真正接受后持续履行；原生跟随和战斗设置约束具体行动，不成为绕过已拒绝任务的另一条入口。玩家在系统层暂停或停用 AI 的管理操作始终有效，不受角色性格影响。

角色目标、真正承担的承诺与实际发生的结果分别记录。愿望和提议不自动成为任务；真正接受且可执行的工作形成持久任务，假承诺不自动生成履行任务。进展、受阻、失败和完成依据真实游戏结果记录；下次 LLM 思考获得此间行动摘要。角色可以对经历形成主观看法，但不能据此覆盖实际结果。

用户随后确认 Q12—Q15。真正接受的新任务默认加入待办；角色同意优先处理时暂停旧任务并保留进度，之后复核恢复。普通聊天不清空工作，假承诺不加入真实执行队列。明确取消指定工作时取消；目标永久失效或角色明确决定放弃时，结束任务并保留原因。

普通界面显示玩家可知的行为与进度、角色自述以及模型连接、等待等系统状态；完整真实目标、隐藏动机及假承诺详情仅在主动打开的调试视图显示。接受玩家无法从普通面板直接检查所有内部状态的代价，以保留角色信息边界与欺骗玩法；系统诊断仍须准确。

该决定已进入本地实现：真实接受、拒绝、任务回执和模型陈述分别记录，普通界面只展示玩家实际可见的动作及角色自述。第一版任务范围及可调工程参数见[完整设计草案](../project/companion-avatar-design.md)，读档边界见 [ADR 0003](0003-world-bound-avatar-history.md)。具体平台及测试结果见[验收契约](../../companion/docs/acceptance.md)。
